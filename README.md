# 🍽️ Turkish Restaurant App

A modern mobile application for ordering traditional Turkish cuisine, built with React Native.

## ✨ Features

- Beautiful splash screen with animations
- Browse menu by categories (Main Dishes, Appetizers, Desserts)
- Search functionality
- Cart management with animations
- Secure payment processing
- Modern and user-friendly interface

## 🚀 Tech Stack

- React Native
- React Navigation
- React Native Reanimated
- Expo

## 🛠️ Installation

```bash
# Install dependencies
npm install

# Start the app
npm start
```

Then scan the QR code with Expo Go app or run on iOS/Android emulator.
